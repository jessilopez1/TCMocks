One shared Google Sheet, one tab per coach. Your records stay in your tab. An admin with access to the Sheet can see all tabs. Setup takes about 5 minutes, done once.
1Open Google Sheets and create a new spreadsheet — name it "HR Mock Sessions" (share it only with people who need admin access)
2Go to Extensions → Apps Script, delete the default code, and paste the script below
3Click Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy
4Copy the deployment URL → paste it in the field below → done. Each coach does this with the same Sheet but their own URL is the same (one deployment covers everyone)
function doPost(e){
  var data=JSON.parse(e.postData.contents);
  var ss=SpreadsheetApp.getActiveSpreadsheet();
  var tabName=data.coach||'Unknown coach';
  var sheet=ss.getSheetByName(tabName);
  if(!sheet){
    sheet=ss.insertSheet(tabName);
    sheet.appendRow(["Date","Candidate","Programme","Role","Company","Score","Readiness","Feedback","Notes"]);
  }
  sheet.appendRow([data.date,data.name,data.programme,data.role,data.company,data.score,data.readiness,data.feedback,data.notes]);
  return ContentService.createTextOutput("ok");
}

How the tabs work: The first time you export a session, the script automatically creates a tab named after you (whatever you typed in "Your name" in Setup). Every session you save after that goes into the same tab. If a second coach uses the same Sheet with their own name, their sessions go into a separate tab automatically. You each only see your own tab unless you have full Sheet access.
